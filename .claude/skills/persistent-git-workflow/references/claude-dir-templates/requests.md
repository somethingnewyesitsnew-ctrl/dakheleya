# REQUEST LEDGER

Every substantial user request gets a unique `REQ-xxx` ID here:
USER REQUEST → TASKS → CHECKPOINTS → FINAL RESULT

Small, single-step requests don't need a REQ entry — log them directly in tasks.md.

## Record format

```markdown
## REQ-0NN
Date:
Original Request Summary:
Objective:
Status: PENDING | IN_PROGRESS | COMPLETED | BLOCKED | CANCELLED
Related Task IDs:
Completed Tasks:
Current Task:
Remaining Tasks:
Final Outcome:
```
