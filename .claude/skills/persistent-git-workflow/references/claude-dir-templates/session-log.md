# SESSION LOG

Every Claude session that performs meaningful project work gets a `SESSION-0NN` entry here.
Never record secrets/tokens/credentials in this file.

## Record format

```markdown
## SESSION-0NN
Date:
Environment:
Starting Checkpoint:
Active REQ:
Active TASK:
Work Completed:
Files Changed:
Validation Performed:
Checkpoint Created:
Ending Status:
Exact Next Action:
```
